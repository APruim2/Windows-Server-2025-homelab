# Windows-Server-2025-homelab

## Overview

This project documents the creation of a Windows Server 2025 Active Directory lab using Oracle VirtualBox.

The lab simulates a small business environment and demonstrates common Help Desk and Systems Administration tasks.

## Technologies Used

- Windows Server 2025
- Windows 11 Pro
- Oracle VirtualBox
- Active Directory Domain Services
- DNS
- TCP/IP
- PowerShell

## Skills Demonstrated

- Windows Server installation
- Static IP configuration
- DNS configuration
- Active Directory
- Organizational Units
- User management
- Security groups
- Domain joining
- Windows networking
- Troubleshooting
